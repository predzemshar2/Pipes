# Pipes
Система определения количества и контуров труб по фотографии

# Алгоритм
На тестовых фотографий труб (папка Pipes) размечены ответные маски (белые контуры профилей труб на черном фоне) - папка Answears.
<img width="435" height="141" alt="augmented" src="https://github.com/user-attachments/assets/19198c35-bb06-4c7b-8f71-bf1db9f869a9" />

Создана нейронка по архитектуре U-NET (на PyTorch), на вход подавались фото труб с трансформациями (рандомный участок фото с поворотом и масшатоб), на выходе должна выдываться маска контуров профилей труб (с теми же трансформациями).

Таким образом из тестовых фото получены контуры труб, дальше передается обработка во вторую нейронку, обученную на определении типа контура трубы (простая модель с двумя сверточными слоями, макс-пулами и релу, далее дропаут и 2 полносвязных слоя).
<img width="997" height="343" alt="test" src="https://github.com/user-attachments/assets/dcea9910-6a8d-4b24-ab46-20c81c1a460d" />

На выходе из исходного фото получено фото с обводкой предсказанных контуров труб, количество по типам труб.
